# The Capitol News (TCN)

A responsive editorial website prototype with four distinct news desks and a shared modern design.

## Sections
- `index.html` — **Top Stories**, the all-news front page combining coverage from every desk
- `politics.html` — **Politics**, focused on U.S. government, Congress, legislation, public policy and political leadership
- `world.html` — **World**, focused on foreign affairs, diplomacy, international relations and major news from other countries
- `elections.html` — **Elections**, focused on campaigns, candidates, voting information, key dates and official results; no reader polls
- `article.html` — shared article-reading template
- `styles.css` — shared responsive design system
- `app.js` — mobile navigation, sitewide story-search prototype, date display and newsletter demo

## Design
- Black: `#090909`
- Red: `#fc2121`
- Responsive editorial typography, centered desktop navigation, story cards, desk-specific pages, and mobile navigation

## Prototype notes
- TCN is a parody publication. Story copy and imagery are illustrative, not verified current reporting.
- Search filters a small built-in sample index; it does not search the live web or a news database.
- Newsletter signup is a demo interaction only and does not store or transmit email addresses.
- Elections pages do not include polls. Verify election dates, candidates, voting instructions and results with official election authorities before publication.
- Images are loaded from Unsplash URLs and Google Fonts are loaded remotely.

## Preview locally
Open `index.html` in a browser. For deployment, enable GitHub Pages in repository Settings and select the `main` branch with `/ (root)` as the publishing source.
