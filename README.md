# The Capitol News (TCN)

A responsive editorial news website prototype focused on government, legislature, public policy, world affairs, politics, and elections.

## Pages
- `index.html` — homepage / Top Stories
- `article.html` — article reading template
- `elections.html` — Elections & Polls, including a clearly labeled demo poll and results-center placeholder
- `styles.css` — shared responsive design system
- `app.js` — mobile navigation, search prototype, newsletter demo, and poll interaction

## Design
- Black: `#000000`
- Red: `#fc2121`
- Responsive editorial layout, story cards, bylines, newsletter block, and mobile navigation

## Important prototype notes
- Story copy and election poll percentages are illustrative, not current reporting or real polling data.
- Search and newsletter signup are demo interactions only; they do not query an index or store user information.
- The election results area is a placeholder. Connect authoritative election data sources and show timestamps before launch.
- Images are loaded from Unsplash URLs and Google Fonts are loaded remotely.

## Preview locally
Open `index.html` in a browser. For deployment, enable GitHub Pages in repository Settings and select the `main` branch with `/ (root)` as the publishing source.
